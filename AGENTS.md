# screen-cap

An open-source macOS screenshot app: capture (area, window, fullscreen, scrolling, timer),
annotate, OCR, pin and save, from the menu bar with global shortcuts. Screenshots, editing,
and saving only; screen recording is deliberately later. "Done" for v1 is every row marked
v1 in the feature matrix in `docs/PLAN.md`.

## Status
First working build (2026-10-31): M0–M7 merged, 337 tests green. Capture (area/window/fullscreen/
previous/timer/all-in-one/scrolling), Quick Access, Annotate editor, OCR/QR, pins, history, URL
scheme, settings all run from `make run`. M8 ship (#29): DMG, release workflow, Sparkle (off until keyed), cask, README. Next: real-world QA passes.
Grant Screen Recording to `build/ScreenCap.app` in System Settings. Ad-hoc builds keep the default
cdhash requirement, so every rebuild needs a fresh grant: run
`tccutil reset ScreenCapture com.contractorkeith.screencap` and re-grant. Never pin an ad-hoc
requirement to the identifier (#146: any ad-hoc app could claim the grant); `check-bundle.sh`
enforces it. Only Developer ID signing (`SIGN_IDENTITY`) makes grants persist.

## Commands
```bash
make build        # swift build (debug)
make test         # swift test; adds Swift Testing paths when only Command Line Tools are active
make bundle       # scripts/bundle.sh -> build/ScreenCap.app (release, ad-hoc signed, icon, build number)
make run          # bundle, then relaunch build/ScreenCap.app
make dmg          # bundle, then dist/ScreenCap-<version>.dmg (version from ScreenCapKit.version)
make appcast      # Sparkle appcast for dist/ (needs SUPublicEDKey; see scripts/appcast.sh)
make lint         # swiftlint --strict
make clean
pkill -x ScreenCap                                   # quit a running build
# Optional, Xcode users only: xcodegen generate && open ScreenCap.xcodeproj
```

## Conventions & Gotchas
- Swift 6 strict concurrency. SwiftUI for windows and settings, AppKit for overlays,
  panels and the menu bar. Capture with ScreenCaptureKit only (no `CGWindowListCreateImage`).
- Logic lives in the `ScreenCapKit` Swift package so it can be unit-tested without the app.
- SwiftPM-first (overrides PLAN §8): the root `Package.swift` builds and tests everything with
  Command Line Tools alone, no Xcode. `project.yml` (XcodeGen) is a secondary path for Xcode
  users and is not verified in CI. Add ScreenCapKit files under its existing subfolders; no
  `Package.swift` edit needed. Use `make test`, not bare `swift test`, on a CLT-only Mac:
  bare `swift test` can't find the `Testing` module there. If Xcode is installed but its
  license isn't accepted, `export DEVELOPER_DIR=/Library/Developer/CommandLineTools`.
- The `.xcodeproj` is generated by XcodeGen from `project.yml`; never commit it.
- Global shortcuts use KeyboardShortcuts pinned to 1.x: every 2.x release has `#Preview`
  macros that Command Line Tools can't expand. Move to 2.x only if CI and local builds use Xcode.
- Tests needing real `UserDefaults` use `TemporaryDefaults` (a path suite in `$TMPDIR`) with
  `defer { suite.remove() }`; named suites leave plists in `~/Library/Preferences` even after
  `removePersistentDomain` (#120). Otherwise use `InMemorySettingsStore`.
- VoiceOver labels live in `App/A11y.swift`; icon-only controls get `.accessibilityLabel` from it,
  never an SF Symbol name (#117).
- App-side logic tests live in `Tests/ScreenCapTests` (`@testable import ScreenCap`); keep that logic
  pure (no screen access) so it runs headless.
- Hidden launch options drive captures without key presses (CI smoke tests):
  `build/ScreenCap.app/Contents/MacOS/ScreenCap --capture <area|window|fullscreen|previousArea|selfTimer|allInOne|scrolling|text> [--action save|copy|overlay|annotate|pin] [--window <app>] [--quit]`.
  Launched from Terminal, Screen Recording permission is Terminal's.
- Build number: `bundle.sh` runs `scripts/stamp-version.sh`, which stamps `CFBundleVersion` with `git rev-list --count HEAD` (override with
  `BUILD_NUMBER`) and `CFBundleShortVersionString` from `ScreenCapKit.version`. Sparkle compares
  `CFBundleVersion`, so the source plist's `1` must never ship; `scripts/check-bundle.sh` fails the
  bundle if it does. Needs full git history (CI checks out with `fetch-depth: 0`). CI runs
  `make bundle`, the check and a `--capture bogus --quit` launch (exit 3) on every PR.
- Releases: bump `ScreenCapKit.version` and `CFBundleShortVersionString` together (dmg.sh and a
  test fail on mismatch), date the version's CHANGELOG.md section (0.1.0 is not tagged yet) and use it as the tag message, push an annotated `v<version>` tag; release.yml
  builds the DMG and the GitHub Release. Sparkle stays off until `SUPublicEDKey` replaces the
  Info.plist placeholder. bundle.sh embeds Sparkle.framework in Contents/Frameworks.
- SwiftPM resource bundles (KeyboardShortcuts' localizations) ship in `Contents/Resources`; their generated
  `Bundle.module` only looks in the app root (which codesign forbids), so `App/ResourceBundles.swift` redirects
  it at launch. Without that the Shortcuts pane traps on any Mac without the build checkout (#92).
- Original name, icon, UI, copy, backgrounds, and file format. Do not copy any other app's assets or branding.

## Out of Scope
- Screen recording, GIF, video editor, camera, keystroke and click overlays (later phase).
- Hosted cloud sharing, accounts, teams.
- Windows/Linux.
