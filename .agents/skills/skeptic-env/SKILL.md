# skeptic-env — screen-cap

A macOS menu-bar screenshot app (capture, annotate, OCR, pin, save). Done for v1 is every
row marked v1 in the feature matrix in `docs/PLAN.md`, passing the §7 acceptance checks.

## Stack and commands

```bash
make build                  # swift build (debug)
make test                   # fast tier; use this, not bare `swift test`, on a CLT-only Mac
make lint                   # swiftlint --strict, as CI runs it
make bundle                 # build/ScreenCap.app (release, ad-hoc signed)
scripts/check-bundle.sh     # what CI runs after bundle
make dmg                    # dist/ScreenCap-<version>.dmg
pkill -x ScreenCap          # quit a running build (only one you started)
build/ScreenCap.app/Contents/MacOS/ScreenCap --capture <area|window|fullscreen|previousArea|selfTimer|allInOne|scrolling|text> [--action save|copy|overlay|annotate|pin] [--window <app>] [--quit]
build/ScreenCap.app/Contents/MacOS/ScreenCap --capture bogus --quit   # CI smoke: exit 3
```

If Xcode is installed but its license is not accepted:
`export DEVELOPER_DIR=/Library/Developer/CommandLineTools`.

Scratch data: run tests only with `TemporaryDefaults` / `InMemorySettingsStore`. To run the app
without touching the user's prefs or history, point Save location at a temp dir in Settings and
note what you changed; never edit `~/Library/Preferences/com.contractorkeith.screencap.plist`
by hand. Screen Recording: an ad-hoc rebuild needs a fresh grant
(`tccutil reset ScreenCapture com.contractorkeith.screencap`, then re-grant). If you cannot
grant it, say so and list capture checks as not run.

## What to attack

- Capture: every mode via `--capture`; display change, sleep or a second display mid-capture;
  scrolling capture stop/cancel; timer cancelled; a second capture started before the first ends.
- Quick Access, History, pins: keyboard only, delete/undo, unsaved captures, cleanup rules in
  Settings vs what the app actually deletes and when.
- Editor and redaction: secure blur/pixelate must not be OCR-readable after export or after a
  `.screencap` save (`docs/file-format.md`); reopen old `.screencap` files; corrupt packages.
- URL scheme (`docs/url-scheme.md`): malformed, oversized, unknown actions, paths with traversal
  or symlinks, values outside clamps.
- Packaging: build the bundle and DMG and run the artifact, not `make build`; every SwiftPM
  resource bundle in `Contents/Resources`; Sparkle embedded; build number not `1`.
- Permissions: designated requirement stays cdhash-anchored (#146); onboarding after a rebuild.
- Docs: README install and CHANGELOG commands as typed, from a fresh shell.

## Traps

- The `.xcodeproj` is generated by XcodeGen and never committed; its absence is not a bug.
- KeyboardShortcuts is pinned to 1.x on purpose (2.x needs Xcode macros).
- Smooth blur is cosmetic by design and labelled "not for secrets"; Secure is the default.
- `App/ResourceBundles.swift` redirects `Bundle.module` on purpose (#92).
- Sparkle is off until `SUPublicEDKey` replaces the Info.plist placeholder; not a bug.
- 0.1.0 is not tagged yet.
