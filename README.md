# screen-cap

An open-source screenshot app for macOS: capture an area, window, the full screen or a
scrolling page, mark it up, copy text out of it, pin it on screen and save it.

**Status:** planning. Nothing is built yet. The build plan is in [docs/PLAN.md](docs/PLAN.md).

Its feature list is inspired by [CleanShot X](https://cleanshot.com). screen-cap is an
independent project, not affiliated with or endorsed by CleanShot.
